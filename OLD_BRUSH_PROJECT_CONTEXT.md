## 3 · Hard rules (do-not-touch list)

Breaking any of the following requires user approval — never silently deviate.

- **No invented social proof.** No testimonials, reviews, client logos, awards, metrics or case studies without verifiable evidence.
- **`#clients` stays latent.** Replaced by `#process` in v1 until real evidence exists (photos + written permission + client name).
- **No public pricing / plans.** Quote-based only.
- **Copy in en-NZ.** All visible strings.
- **Contact info is canonical.** Do not paraphrase or substitute placeholders.
- **Imagery convention:** stock and AI-generated imagery uses `alt="Reference imagery"` variants; brand-authentic photography (images 2 and 3) uses honest descriptive alt.
- **Package manager:** npm. Do not switch to pnpm/yarn/bun.

## 4 · Architecture

- Next.js 16 · App Router · React 19 · TypeScript `strict`.
- Server Components by default. Client islands only when justified:
  - `Preloader` — GSAP timeline + sessionStorage guard.
  - `Header` — scroll state + mobile drawer.
  - `ScrollReveal` — GSAP scoped useGSAP.
  - Contact form (Fase 3).
- Tailwind CSS v4 with tokens declared in `@theme` inside `globals.css` — no `tailwind.config.js`.
- Aliases: `@/components/*`, `@/lib/*`, `@/app/*`.
- Content and SEO helpers centralised in `src/lib/content.ts` and `src/lib/seo.ts`. Never inline commercial copy inside a component.

## 5 · Component boundaries

| Layer | Rule |
|---|---|
| Atoms | Presentational only. Accept explicit surface variants (`paper`, `sand`, `green`, `lightgreen`, `gold`). |
| Molecules | Compose atoms + light behaviour. Never fetch data. |
| Organisms | Own a whole section (Header, Footer, HeroBrush, etc.). Consume content from `lib/content.ts`. |
| Templates | Reserved. Only introduce if two organisms share layout scaffolding. |

**Visual differentiation is enforced by design:**

- `Button` = interactive. Never fake as chip.
- `MetaChip` = passive informational label. No hover, no cursor pointer, no border.
- `Divider` = editorial ornament (never as content separator between paragraphs).
- Text link ≠ Button. Never restyle a link to look like a button.

## 6 · Animation categories

Four categories, **kept separate**:

1. **`brushRevealOnce`** — one-shot entry, `ScrollTrigger.once: true`. Currently in `ScrollReveal` molecule.
2. **`plasterScrub`** — scrub-linked to scroll. Reserved for ornaments (Fase 2).
3. **`hoverBrushGlow`** — micro-interactions. Reserved (Fase 2).
4. **`preloaderTimeline`** — one shot on first visit per session. Owned by `Preloader` molecule.

Never mix categories in a single helper. All animations respect `prefers-reduced-motion`.

## 7 · Responsive breakpoints

Verify at **375 · 768 · 1024 · 1440 px** minimum. Mobile-first Tailwind + `useMedia` where JS gating is required (heavy assets are conditionally rendered, not `hidden md:block`ed).

## 8 · SEO & structured data

- `<html lang="en-NZ">` in the root layout.
- Per-route `Metadata` via helpers in `src/lib/seo.ts`.
- `sitemap.ts` + `robots.ts` generated by Next.
- `LocalBusiness` (`HomeAndConstructionBusiness`) JSON-LD injected in root layout.
- `/thank-you` is `noindex`.
- No `aggregateRating` / `review` / `award` fields — omit entirely without verifiable data.

## 9 · Analytics

- Vercel Analytics + Speed Insights only (v1).
- No GA4, no Meta pixel, no consent banner (passive footer + `/privacy` copy is enough for NZ Privacy Act).
- Custom event tracking (`trackCta`) lands in Fase 3 alongside the contact form.
